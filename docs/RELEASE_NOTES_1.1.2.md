# ShellBot 1.1.2 Windows

正式包：`ShellBot-1.1.2-windows-x64.zip`。

本版将 GUI 启动、恢复窗口、前台激活和截图分开处理，以改进同用户 RDP 会话中的应用操作；不是“保证任意后台进程始终能取得焦点”。

- `task_start` 新增 `launch_mode:"gui"`，仅限普通 current_user，确认当前交互会话为 WinSta0/Default 后请求正常显示。仍采用原任务审批、幂等键、Job、超时和取消。后台模式仍是默认值。回执只确认进程创建，另报会话和前台授权交接的真实结果；不会因为启动成功就宣称窗口已显示/聚焦。
- `window_list` 保留可见但最小化的窗口，并返回 `minimized`。这里的应用窗口最小化不同于 mstsc 客户端最小化。
- `window_focus` 增加 `restore`（默认 true）和 `wait_ms`（默认 1500，范围 0～3000）。使用异步窗口恢复，核实窗口身份、租约、人工暂停和布局后再请求前台，并观察最终结果；不依赖截图。API 失败仍不使用残留 GetLastError 猜测原因。恢复/激活尝试后必须重新观察，防止使用旧坐标。
- 保留现有会话绑定，不自动切换到控制台会话或引入 SYSTEM 桌面代理；当前同会话场景先修复原生流程。未使用伪造 Alt、绑定输入队列或永久置顶来取得焦点。

用法和验收矩阵见 [RDP 说明](REMOTE_DESKTOP.md)。[DeepSeek Harness 对照](HARNESS_TOOL_COMPARISON.md) 按固定官方提交记录了可借鉴设计及缺失能力，明确区分可选/实验工具和平台差异。

自动验证采用不创建可见窗口的 GUI 子系统探针，以及拦截实际恢复/聚焦/键盘 API 的原生测试。真实 mstsc 在线且最小化、单实例应用激活、物理窗口交互及 Mac/Linux 原生验收仍需各自环境验证。本版不改真实 RDP 客户端设置，不把本地/模拟通过写成真实 RDP 通过。
