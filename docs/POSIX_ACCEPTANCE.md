# Linux / Intel Mac 集中人工验收

当前开发目标为 Linux x86_64 和 Intel Mac（macOS 13+）。Apple Silicon 暂不纳入本轮。项目、文件、命令、凭据/OAuth、原生管理界面/托盘、远程桌面、媒体/产物、自启/服务、独立所有者审批和数据迁移均已有实现；第十阶段补齐管理员文件/媒体/产物代理及 Mac 命令内存配额，第十一阶段增加按冻结配置授权的多项目共享管理员监督器。第十二阶段完成本机管理员管理、独立审批池及系统授权通道，第十三阶段整合原生后台服务配置、预览与安装启停，第十四阶段补充 Linux 多屏流、有效键盘布局和动态输入设备观察，第十五阶段增加每命令独立监督、Linux 孤儿接管及两平台已识别后代的内存合计采样与回收。第十六阶段补齐长 Data 的本地通信、原生管理路径及迁移检查；第十七阶段补齐候选打包、校验/依赖清单、用户菜单和可选 Mac 签名；真实发布身份、公证及已声明的平台限制仍须分别核对。自动测试和开发包检查通过后，使用同一份最终开发包集中执行下表，不把源码、隔离夹具或生成的服务配置当作人工验收结论。

验收开始时记录包的 SHA-256、程序版本、机器/系统版本、安装路径、应用/项目 Data 位置，以及使用的命令身份。采用独立测试目录和测试客户端；已有 Data、旧包、源迁移目录和失败收据作为恢复材料保留。表中的场景当前均为待人工确认，不会因自动化检查通过而自动勾选。

| 顺序 | 场景 | 验收要点 |
| --- | --- | --- |
| 0 | 候选包与安装升级 | 核对可信摘要、manifest 和运行依赖；Linux 登记/移除菜单、Mac 原 App 打开；固定位置与中文/空格路径；真实签名、公证、隔离下载检查；新旧程序切换、服务路径重新登记，卸载保留 Data/凭据/历史。 |
| 1 | 原生入口与项目表单 | 正确图标、窗口、托盘/菜单栏；关闭、恢复、退出；多目录、只读和 37 个工具独立设置；中文名称不改变固定地址；保存前停后台、摘要冲突拒绝、备份保留；不误启动未勾选的项目。 |
| 2 | 系统凭据与升级 | 实际 Keychain/Secret Service 解锁、拒绝、重新打开、同 UID 换包后的 ACL；凭据不出现在界面、URL、日志和包内；不能解密时不生成替代明文或新凭据。 |
| 3 | 外部 MCP 与 OAuth | 用实际客户端和用户配置的 HTTPS 代理验证工具发现、文件/媒体/产物呈现；PKCE、拒绝、限时与持续授权、访问到期续期、刷新轮换、重启、撤销；删除同名重建不继承授权。 |
| 4 | 普通文件与命令 | 文件分页、变更检测、备份、跨目录只读；普通命令的真实 UID、参数、stdin、输出、取消、超时、关闭和重启不重放；restricted 环境实际越界、网络和 fork 拒绝，拒绝不能回退为普通命令。 |
| 5 | root 管理员会话 | 分别验证本机“管理员”页系统授权和所有者显式 sudo 命令入口，使用同一份 root 拥有的完整程序和一致注册表，独立 root Data；核对普通/管理员的实际 UID、文件拥有者和访问效果；共享监督器一次允许 A/B、拒绝 C，停止/撤销 A 不影响 B，变更注册表不扩大旧许可，监督器或持有授权的窗口消失撤销子代理，关闭窗口保留托盘，拒绝/取消授权不重试，原生项目状态和两池审批准确；没有代理、配置不匹配、普通审批或其他调用者不能继承权限。 |
| 6 | 管理员文件、媒体与产物 | 显式 identity:administrator 读写与管理 root 测试文件、PNG/JPEG、PDF/DOCX/XLSX/PPTX、上传/下载；只读仍生效、备份在 root Data，上传每步保留身份且不覆盖；撤销或关闭会话不提交暂存内容；命令关闭时文件可用而命令拒绝。 |
| 7 | 本机与远程所有者审批 | 实际浏览器和代理下独立凭据认证；检查普通与管理员审批池，核对摘要/实例/策略；修改后拒绝旧决定；项目/OAuth bearer 不能审批；页面没有项目启停、OAuth 批准或代理启动能力。 |
| 8 | 远程桌面系统授权 | Mac 的屏幕录制、辅助功能、输入监控；Wayland 的共享确认、实际 PipeWire 画面、输入和剪贴板；拒绝、撤权、关闭共享均不可用，不绕过系统确认。 |
| 9 | 桌面真实操作与中断 | 多屏、裁剪、Retina/缩放坐标、同屏拖动/滚轮、组合键、当前布局可表示的文字和中文剪贴板；Wayland 多屏选择、逐流缩放、缺少位置的显示区域和布局变化后重新连接；像素尺寸不变的逻辑布局变化不能保证自动发现，须先停止共享、重启受影响项目后再连接并确认共享；X11 非零键盘组、CapsLock/NumLock、Level3、按住普通键、设备热插拔后暂停/恢复及新租约；实体键鼠/紧急暂停、锁屏、切换用户/前台窗口、租约超时及本机恢复。Wayland 的窗口管理、全局人工输入检测及前台核对是已声明的平台限制，不误记为通过。 |
| 10 | 原生服务、重启与登录 | 在“服务”页分别预览、登记、刷新、启停、卸载用户/系统服务；核对普通运行账户、明确启动列表、状态检查时间、表单变更后拒绝旧预览、外部修改拒绝接管；系统授权拒绝/取消/超时不重试，窗口退出和重开保留服务且不接管，登录自启与后台登记独立；重启前不手工启动程序，确认首次登录/无人登录时序、图形会话、系统凭据/加密目录就绪和端口，不重放任务、输入、审批或桌面租约；卸载保留 Data/凭据/日志，迁移前须卸载。真实系统安装、重启和注销由所有者安排。 |
| 11 | 数据迁移与恢复 | 使用超过 512 字节的中文 Data 路径运行和重启管理器、多个项目及打包后的应用，迁移后确认旧入口跟随、独立审批与凭据仍正常；实际项目/应用 Data 迁移后核对凭据、持续授权、刷新/撤销历史；旧源保留、旧入口跟随或拒绝旧副本；取消准备、服务路径重新登记、独立 root 状态另行处理；故障前后不重复执行操作。 |
| 12 | 长期运行与资源边界 | 长连接、定期刷新、多个项目、挂起/唤醒、网络中断、空间不足/突然终止后的恢复；多命令取消互不影响、已识别脱组后代回收、内存合计超限、工作进程或任务代理异常退出后的清理。Linux 保留每进程地址空间限制并接管孤儿；Intel Mac 无法保证采样前快速脱离的孤儿。两平台合计配额均为采样终止，均不等于恶意账户命令的完整资源沙箱。 |

每项记录成功、失败或明确不适用，并关联本次包身份和可复现步骤。root、系统隐私许可、外部客户端、重启登录及真实 GUI 的结果分别保存，不能互相代替。
