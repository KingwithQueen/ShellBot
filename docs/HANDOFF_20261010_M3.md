## 已完成与入口

- `--manager --http --projects FILE --manager-data-dir DIR`：普通管理器可选开启共用回环端口；省略 --http 保持 M2 本机入口。
- `/projects/ID/mcp`：逐项目路由与 bearer 绑定；另一项目令牌拒绝；MCP 参数不能改变 project、actor 或策略版本。
- `/projects/ID/healthz`：只在正确认证且项目工作进程运行时返回 ready。
- `/mcp`、`/healthz`：只绑定显式 gateway.default_project_id，不从令牌或请求体推断默认项目。
- `--project-links ID --manager-data-dir DIR`：返回本机及可选公共 MCP 地址、凭据引用和状态，不返回令牌值或探测域名。
- 启用项目要求有效、不同的 32～256 字节可见 ASCII 令牌；缺失、无效或重复值阻止整个网关启动。凭据不进入工作进程、任务环境、日志或地址。
- 真实 HTTP 请求头转发到固定工作进程，按无会话协议校验；JSON、协议错误状态和空 202 保留。本机 owner 请求仍按原协议语义处理。
- HTTP actor 为 project-mcp，本机请求为 manager-owner；任务、幂等键和旧文件审批按 actor 绑定。
- 固定四个 HTTP 线程、四个应用层等待连接位置；认证后预留项目，同项目忙返回 429。通信共用 8 秒期限，失败清理本人 Job、返回 503，不自动重启/重发。

运行与边界见 [PROJECT_GATEWAY.md](PROJECT_GATEWAY.md)、[PROJECT_MANAGER.md](PROJECT_MANAGER.md)。主计划与权限规则以 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)、[EXECUTION_PERMISSIONS.md](EXECUTION_PERMISSIONS.md) 为准。
