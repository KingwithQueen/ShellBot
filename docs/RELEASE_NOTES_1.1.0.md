# ShellBot 1.1.0 Windows

正式包：`ShellBot-1.1.0-windows-x64.zip`。

本版根据 2026-10-31 工具复测反馈加固内部错误诊断。工具回执增加服务端请求关联编号；空返回、类型异常、结果编码失败/超限、工作进程失联都会返回可定位的错误，保留调用方原始 JSON-RPC id。返回失败阶段、主机实例、执行状态及重试指引，避免将未知执行结果误认为未执行。服务端不会自动重放任务或桌面输入。

修复返回字符串对已释放参数内存的依赖，覆盖 compact 参数归一化、工具调用及批量归档的临时参数。批量 compact 回执仍保留失败项和未尝试 ID；task_output 的 text/bytes/both、入口进程/Job 状态及 RDP/聚焦诊断继续保留。

内部错误日志仅记录关联编号、工具、阶段、原因、参数类型计数及诊断边界栈地址，不记录完整命令、输入正文和认证。工作进程崩溃后的管理器诊断栈不能替代崩溃现场；本轮没有证明原反馈中的偶发错误已在原环境消失。具体字段及重试方法见 [内部错误](INTERNAL_ERRORS.md)。

新增版本递增脚本与构建/打包一致性校验，后续按 `1.1.9 → 1.2.0`、`1.9.9 → 2.0.0` 进位，见 [版本规则](VERSIONING.md)。

验证包括 Debug/Release 原生故障注入、隔离 MCP/HTTP 的工作进程中断、缺失文件重复读取、日志脱敏、版本进位，以及已有任务、文件、文档、图片、升级和桌面诊断回归。正式包附逐文件哈希和实际验证摘要。真实外部客户端、原反馈机器偶发问题、mstsc 最小化、实体键鼠/UAC 与 Mac/Linux 原生验收仍需各自环境验证；本版未修改实际 RDP 客户端设置。
