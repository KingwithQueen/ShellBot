# ShellBot 1.0.2

发布日期：2026-10-22。Windows x64 正式便携版。

修复选择项目存储目录时浏览窗口空白的问题。新建项目、应用数据位置和权限目录三个入口统一使用 Windows 文件夹选择器，调用前在当前界面线程初始化 STA COM，并在关闭后配对释放。选择器从输入路径或最近存在的父目录开始浏览，支持中文目录；取消时保留原路径。项目默认工作目录继续跟随存储目录，自定义工作目录保持原值。

补齐数据目录中的 Runtime/Home/Desktop，避免便携运行环境的 USERPROFILE 指向数据盘后，Windows 选择器因桌面目录不存在弹出“位置不可用”。该目录属于程序运行时数据，不修改 Windows 用户目录设置。

主程序、桌面入口和受限执行探针的版本统一为 1.0.2。沿用单托盘、关闭窗口继续后台运行、退出停止全部项目的行为；权限、120 秒桌面控制租约上限和 OAuth v3 数据格式保持一致。

升级前先从托盘退出旧版，备份并保留 Data、ShellBot.storage.json 和原 Windows 账户，再替换程序文件。发布包不包含项目数据或凭据。

本机验证记录位于 build/release-1.0.2；实际完成范围以包内 validation/acceptance.json、目录选择专项和本机解压报告为准。真实客户端持续连接、实际 UAC、物理多屏 DPI、独立 Windows 环境和长期运行分别验收。
