## 实现和使用

新增 `WinShellBot/platform/manager_ui.c/.h`，使用 Windows 原生控件，C17 与静态 CRT，产品不依赖 Python、Node、浏览器或 .NET。普通所有者通过 `--manage --manager-data-dir DIR` 连接已运行的管理器；管理器与窗口必须使用同一 Data 位置。窗口不会隐式启动管理器，关闭窗口不会停止它。

项目表及详情显示状态、MCP 地址、文件范围和只读目录、审批、默认执行身份、管理员许可和代理状态。启动/停止、暂停/恢复只作用于所选项目，实际能力诊断另查询运行实例。请求在线程中执行，有界通道失败时显示错误，不重发副作用。停止与暂停前确认活动任务会结束；启动管理员前确认后调用原异步 UAC 协议，停止代理前确认会影响全部管理员任务。

新增本机 `management-status`、`project-pause` 和 `project-resume`。暂停撤离本项目普通/管理员后端并终止本人任务，保留其他项目；标记 paused，项目 HTTP 不可用，普通 project-start 拒绝。明确恢复创建新实例、读取历史并中断旧许可，旧任务键不能重放；暂停仅本管理器有效，不写回配置。暂停清理遇到 cleanup_required 时保留该状态，恢复须先成功清理。

远程所有者 API 保持有限能力；项目 MCP 和远程令牌不能调用新管理命令。配置创建/更新仍导出新文件并明确重启；窗口不支持直接修改、删除或在线重载。当前 GUI 最小逻辑窗口约 1020×660；较小有效显示区域可使用命令行，多屏 DPI 和其他系统仍需验收。详细说明见 [PROJECT_MANAGEMENT_UI.md](PROJECT_MANAGEMENT_UI.md)。

## 候选包与失败保留

新增 `scripts/package-candidate.ps1`，要求当前源码集合/摘要、Release 主程序与产品探针、M1–M7/核心报告及当前 M5/M7 实际提权报告。它保持旧 package-test.ps1 的 dev.7 门槛。候选目录和 ZIP 使用新名称，包含主程序、SandboxProbe、只读/关闭执行示例、说明、许可证、收据与 SHA256SUMS，不含 Data、活动配置或开发夹具。

`build/validation/m7-package-receipt.json` 记录候选包确切路径和 SHA-256；`x64-Release-m7-package.json` 验证 ZIP CRC、全部文件摘要、x64/静态 CRT 依赖、解压程序的实际 GUI/任务，以及 Unicode/空格目录中的启动脚本。运行时使用外部固定操作开发夹具，夹具不是产品依赖。候选外部验收 pending 不写作通过；正式发行前仍需完善项目版权信息。

早期原始失败报告/测试目录保留，索引 `m7-initial-validation-failures.json`。首次编译修正宏重复、ListView 宏 else 和缺少声明；GUI 修复初始 DPI 缩放。测试 HTTP 名称遮蔽与诊断字段断言均修正，诊断最终绑定真实恢复实例。一次并行 Release 核心在一秒期限的备份预算夹具 approve 失败，原退出原因未保存；将预算夹具设为五秒期限，在第 65 次请求前明确等待旧许可过期，Debug/Release 核心复测通过。未将它宣称为产品权限故障或修复。

硬链接对照在当前文件系统不支持，明确 skipped。历史 HTTP close 重置仍待调查，核心使用 SkipCloseProbe。正常账户/管理员程序仍保留系统权限；运行期 allow/revoke 与 pause 不持久化，各 backend 预算分开，不自动清理历史或回滚副作用。
