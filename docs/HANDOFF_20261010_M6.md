## M6 实现

配置增加可选 `gateway.owner_token_env`。所有者令牌与项目令牌、变量名独立，不进入 worker、管理员代理或任务环境。HTTP 提供 `/owner`、静态资源及有限 `/owner/api`，认证在正文和项目查找前执行；仅允许项目状态、待办、完整请求查看、绑定后批准/拒绝/撤销和历史，不允许配置、项目启动、代理启动或 UAC。可信决策 actor 为 `remote-owner`。

原生内置页面显示项目/身份、调用方、完整规范参数、摘要、实例、版本和期限。凭据仅在页面内存保存，输入框连接后清空，清除按钮销毁凭据和状态。页面使用安全文本呈现、同源请求、CSP、no-store、no-referrer 和禁止嵌入；真实 Edge 已验证显示、点击批准和清除。

正常项目增加本人 `approval_status`/`approval_cancel`。声明 2026 URL 能力的客户端收到 `input_required`，客户端 accept 仍需独立所有者实际批准；decline/cancel 仅取消本人请求。未声明 URL、仅 form 或旧协议返回 pending 和无凭据审批链接；结构化结果与文字内容同步。没有开放 SSE、2025 反向 RPC 或标准 MCP tasks。协议依据及配置/API 见 [REMOTE_APPROVALS.md](REMOTE_APPROVALS.md)。

新增 `core/policy/state.c` 和原生受保护日志访问。每 backend 启动产生独立 `state_instance_id`，区别于普通 `host_instance_id`，因此仅管理员代理重启也不能恢复许可。日志核对项目、backend、实例、序号、SHA-256 和私有 DACL，拒绝重解析点、多硬链接及外部授权 ACE。

任务在恢复线程前刷新启动意图，输入在 WriteFile 前刷新意图，记录排队、投递、自然完成、取消、期限和输出限额。历史保留每输出流最多 256 KiB、实际字节数和截断标志；审计不写正文、stdin 或输出。stdin 正文不保存，队列成功、写入成功与程序消费分别表述。

恢复只加载历史：旧活动请求为 interrupted，带 previous_status、active_instance:false 和零剩余期限；已刷新终态保留。没有重启执行、恢复批准或重新投递输入。历史任务的 request_key 禁止跨 backend 实例复用，当前实例原键仍返回原任务；重启后复核并显式用新键。

每 backend 累计 32 MiB、256 个逻辑记录、64 个实例文件，单行 2 MiB，扫描最多 4096 项；普通/管理员分别计预算。末尾没有换行的半条追加忽略并保留，其余损坏、权限错误和预算超限阻止新操作。状态查询和取消保留，记录不自动淘汰或删除。
