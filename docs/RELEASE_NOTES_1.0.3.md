# ShellBot 1.0.3

更新日期：2026-10-22。Windows x64。

移除程序对本机监听端口设置的 1024 下限。连接设置、项目权限中的连接页面、桌面项目目录读取、项目注册表、旧版配置和命令行统一允许 1～65535，支持使用 80、443 等低端口。继续拒绝 0、超过 65535、负数和非整数；默认端口仍为 8765。实际监听需要端口可用。

主程序、桌面入口和受限执行探针的版本统一为 1.0.3。升级时先退出旧版，备份并保留 Data、ShellBot.storage.json 和原 Windows 账户，再替换程序文件。既有 OAuth v3 授权继续沿用。

本轮以端口边界、实际低端口 HTTP 监听和后台核心回归验证改动，收据位于 build/release-1.0.3，构建程序位于 out/x64/Release。为避免影响用户正在使用的桌面，本轮不重跑弹窗测试、不生成正式 ZIP，也不将 1.0.2 的界面验证视为新版验证；完整正式包仍须通过既有打包检查。

清理记录保留在本轮验证目录，保留 1.0.2 回退 ZIP、真实项目数据和历史验证记录。真实客户端持续连接、实际 UAC、物理多屏 DPI、独立 Windows 环境和长期运行继续分别验收。
