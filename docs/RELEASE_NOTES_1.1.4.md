# ShellBot 1.1.4 Windows x64

本版针对真实 mstsc 登录/最小化环境完善窗口交互，先更新 Windows，Mac/Linux 未重新移植。

- uia_action 增加 focus_mode:foreground/background，默认保留前台要求。显式后台模式直接调用已观察目标的 pattern，无需先聚焦或截图；继续要求控制许可/租约、未暂停的解锁输入桌面、稳定身份和可用控件。
- uia_tree 与后台语义动作不再因无关窗口前台变化过期；人工输入 epoch、期限、显示布局、目标窗口/控件和权限变化仍会拒绝请求。动作后刷新，超时不自动重放。
- UIA 辅助线程统一 Per Monitor V2 与物理像素，修复 RDP 缩放下 UIA/window_list 坐标单位不同。
- 会话诊断增加明确锁定标志、光标 API 结果、前台是否存在和未探测像素状态。已知锁定会话即使 WTSActive 也不能操作。能力报告增加 uia_background_patterns_supported。

真实 RDP 展开时已验证自建窗口的后台中文写入/读回、按钮单次调用、聚焦与抓屏；mstsc 最小化且未锁定时，后台中文/按钮仍成功，真实前台和 GDI 抓屏失败得到如实报告。一次切换触发人工暂停，动作被拦截；经用户明确允许恢复一次测试控制后完成验证并恢复暂停。没有修改真实 RDP 设置或现有安装。

最小化时的物理键鼠、前台和像素仍依赖连接端持续渲染；适用 mstsc 的配套工具见 [RDP 说明](REMOTE_DESKTOP.md)。仅对自建 Win32 窗口做了本机实测，其他应用/提供者、多屏/UAC、其他客户端和 Mac/Linux 原生环境仍需分别验收。UIA 语义模式不等于完整后台桌面。

接口、示例和回执含义见 [交互工具](INTERACTIVE_TOOLS.md)。升级后重新连接 MCP 客户端以刷新工具定义，现有项目权限不会自动增加。版本继续按 A.B.C（低两位各 0～9）进位。

已知回归事项：Debug 批量任务检查再次出现单次 worker_disconnected_deadline_or_invalid_reply（任务启动回复超过现有期限），与 1.1.3 记录过的现象相似。原始报告和审计保留，根因尚未确认；本版没有修改任务期限、自动重放或声称修复此问题。具体独立复测及同程序摘要见交付包 validation-summary.json。

一次 Debug 更新器测试的启动提前返回，旧测试没有记录原退出码/错误输出；增加测试诊断后，同一更新程序在全新模拟安装中完整复测通过，原失败仍保留。此轮没有修改更新器产品代码，也未将该次失败归因为已确认的问题。
