## 实现与边界

新增 core/tools/transfer.c，接入工具、项目权限、审批、原生受保护文件和管理器/共享管理员生命周期。注册 32 个项目工具，上传为写入，bit 31 掩码有效；旧全工具掩码改用 UINT32_MAX，避免移动 32 位。旧 --config / legacy_config 隐藏上传下载，桌面工具索引范围保持 15–26。manager.example.json 的只读示例只启用下载，上传需显式启用工具和目标写权限。

用户确认同时上传和下载。artifact_download open 批准后保持真实源读句柄、返回文件名、大小与完整 SHA-256；read 沿 next_offset 返回 Base64 和块摘要，最多原始 32 KiB，只能重试最近一块及相同 max_bytes。下载不修改源，不是复制快照。结束关闭源；取消完成下载后也清除最后块，原有效期过后不能读取缓存。

artifact_upload open 必须声明准确 size / expected_sha256 / request_key；批准前只核验目标父目录元数据，批准后才建立私有 spool。write 接收规范带填充 Base64，按 next_offset 追加，最近一块相同重试不重复写入，改变字节拒绝。commit 验完整大小及摘要，在固定父目录写入并刷新临时文件，再禁止覆盖地重命名；不建父目录，不覆盖、不执行、不解包。零字节文件支持。成功 commit 再调用只返回历史回执，外部后改/删除目标也不会重写；取消已提交上传不回滚。

许可与编号绑定本项目、原实际 actor、策略版本、后端实例和普通/管理员注册表；HTTP project-mcp 不能被本机 manager-owner 使用。同一项目凭据共享的客户端属于同一 MCP actor，没有额外每聊天身份认证。正常项目沿用 always / workspace_auto / never；完整传输 open 最多 64 MiB，不套用 fs_read 的 1 MiB 分页总量。open 的完成许可仍可撤销，读块、写块和新 commit 检查原许可及期限。status/cancel 仍允许本人在工具关闭或审计故障后查询/清理。

单文件 64 MiB；每后端 8 个活动、声明/源合计 256 MiB、32 个保留记录。ttl_seconds 1–900，默认 300，实际批准可能更早过期。活动到期在下一次传输调用时清理；停止/退出或崩溃关闭 delete-on-close 私有 spool，重启不续传，完成/失败回执不静默淘汰。日志只存规范参数摘要，不存 Base64；open 私有审批历史不恢复传输。普通和管理员独立，授权更新释放对应管理员传输。

产品仍为 C17、无新增运行依赖。客户端须自行发送/组装块，没有匿名 URL 或自动附件适配。未实现传输后台任务、独立 I/O 硬超时或掉电事务；commit 中崩溃可能留下工作目录临时文件，或文件已提交但未收到回执，须核对实际效果而不能自动重放。详细 API 与配置示例见 [ARTIFACT_TRANSFER.md](ARTIFACT_TRANSFER.md)。
