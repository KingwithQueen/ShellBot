# ShellBot 1.0.1

发布日期：2026-10-22。Windows x64 正式便携版。

本版在已提交的 1.0.0 图标与单托盘版本基础上更新版本号。主程序、桌面入口及受限执行探针的程序版本与 Windows 文件版本统一为 1.0.1；打包脚本按当前版本选择发布说明和验证目录，并记录实际源码提交及本地修改状态。

沿用项目优先的原生 Win32 管理界面与自定义图标。只保留管理程序的托盘图标，项目桌面控制入口集中在托盘菜单；关闭窗口后项目继续运行，从托盘退出时停止本实例全部项目。完整功能及设计范围见 [1.0.0 发布说明](RELEASE_NOTES_1.0.0.md)。

权限、桌面控制租约及数据格式均未变更。升级前从托盘退出旧版，备份并保留 Data、ShellBot.storage.json 和原 Windows 账户，再替换程序文件。1.0.0 的 OAuth v3 数据与既有长期授权继续使用。

本机验证记录位于 build/release-1.0.1，发布包的 validation/acceptance.json 绑定实际程序、源码及测试摘要；解压运行记录与清理收据保存在本机验证目录。历史原始报告及失败记录保留，旧候选程序与压缩包按清理收据移除。真实客户端持续连接、实际 UAC、物理多屏 DPI、独立 Windows 环境与长期运行仍分别验收。
