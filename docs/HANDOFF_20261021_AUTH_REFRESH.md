## 已实现修正

管理窗口后台查询不进入前台忙碌样式；按钮先计算最终可用状态，仅在状态真正改变时调用 EnableWindow。项目 ID 结构未变时不再清空和重建列表，逐单元格比较文字；上下文文字也只在变化时更新。保留选中项目、阅读位置、文本选区和诊断。后台查询时的点击在结果返回后继续，并核对原项目，避免切换选择后对错项目执行。窗口使用 WS_CLIPCHILDREN 避免父窗口背景擦除子控件。

最终回归捕获启动瞬间全局“客户端授权”入口被选择绑定误拦的边界，原始 382 项停点保留在 `preserved-initial-navigation/oauth-debug.json`。修正为只有项目相关操作核对原项目，授权、新建、连接、数据位置和管理员等全局入口不受首次自动选中项目影响；随后重新构建并对最终程序重新回归，不沿用旧摘要的通过结果。

项目保存先比较规范化的实际配置。完全未改动时不写新快照、不重启；仅显示名称或自动启动变化时保存界面元数据，不增加策略版本、不停止工作进程。真实权限、目录、工具和凭据变化仍推进策略版本、停止相关工作进程并要求重新授权。

OAuth 续期保留仍未过期的旧访问凭据原到期时间，最多 8 份旧访问凭据及当前凭据；达到上限返回有界的 429，当前续期代数和可用访问凭据不变，过期后释放名额。仍严格轮换续期凭据，重用任何旧代数撤销整条连接；所有旧、新访问凭据共同受项目、策略版本、到期、移除客户端和撤销控制。可用旧访问凭据也能用于撤销整条连接。没有接受刷新凭据重放的宽限窗口。

OAuth 私有存储写版本 2，兼容读取版本 1；访问凭据历史存的是摘要并继续整体 DPAPI 加密。旧凭据历史数量、字段与原到期时间均有校验，存储上限 512 KiB。回退 dev.24 须恢复更新前的数据备份，旧版不能直接读取新格式。

项目 MCP 短请求不再因同项目锁瞬时占用立即返回 429，而在四个既有 HTTP 工作线程内最多等待 1 秒；超时、停止和长请求仍有界。没有增加线程、后台命令或项目权限。
