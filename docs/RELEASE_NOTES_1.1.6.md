# ShellBot 1.1.6 Windows x64

修复操作回执累计 64 条后无法继续使用的问题，并增加显式应用后台租约，用于已锁定/断开的同用户会话中的普通应用。

- 完整回执自动按槽位与响应字节压力回收；保留精简防重放摘要。旧写入/输入键不会因回收而再次执行，状态仍可区分缓存回执与已回收回执。
- 待审批、运行中、分页/传输许可继续保护；task_archive 仍只释放所选任务。operation_budget 新增可回收、受保护、可用槽、累计回收、字节及摘要统计，host_capabilities 也可独立查询。
- 持久状态索引可轮换已完成读取快照，原磁盘日志保留；不会为了回收读取记录丢弃任务防重放键或活动授权。
- desktop_lease 增加 session_mode:interactive/application_background。默认不变；后台模式只允许普通应用窗口观察、窗口截图及明确的后台 UIA pattern，锁定/连接状态改变即失效。
- 后台模式不解锁、不登录，不访问输入/安全桌面，不允许真实键鼠、聚焦、剪贴板或整桌面截图；人工暂停和观察/控制租约的区别继续有效。

Z620 真实锁屏/断开测试中，普通 GDI 窗口已通过后台中文写入读回、按钮 0→1→2、PrintWindow 的橙→蓝→橙更新核对，连续观察跨过 64 条后继续运行。WGC 在该状态无帧；D3D11 的后台语义操作成功，但兼容截图曾是旧帧，不能宣称锁屏下任意 GPU 图形都可见。GPU/物理输入需要独立且已认证的可渲染会话或虚拟机，见 [远程桌面说明](REMOTE_DESKTOP.md)。

本轮先完善 Windows。Mac/Linux 没有重新移植，现有 Z620 正式安装没有被自动替换。升级后请重新连接 MCP 客户端刷新 session_mode 等定义。测试与原始失败/复测范围以包内 validation-summary.json 和本机交付收据为准。历史 Debug 任务启动偶发回复超时等问题未被本轮功能修复冒充已根治。
