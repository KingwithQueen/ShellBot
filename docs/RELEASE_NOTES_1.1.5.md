# ShellBot 1.1.5 Windows x64

新增不聚焦窗口截图，与现有 UIA 后台模式配合，在真实 mstsc 最小化环境中完成看图、操作、再次看图验证。

- desktop_capture 增加 window_id/screen_id 和 capture_backend:auto/wgc/printwindow。auto 优先 WGC，无帧、失败或疑似全黑时兼容回退 PrintWindow；原桌面/区域截图保持原用法。
- 窗口模式不聚焦、不恢复窗口，不回退为屏幕 DC。保留租约、同用户/会话/权限、解锁输入桌面和观察/目标身份保护。
- 捕获/绘图/编码在独立普通用户进程运行；私有管道持续读取大图片，主线程继续检查取消与身份，避免逐块轮询拖慢传输。图像容量上限不变。
- 回执分别列出后端阶段、错误、编码字节数、疑似空白、物理映射和选定路径。窗口像素不能直接当成全局输入坐标，API 成功不被当作应用结果证明。
- PrintWindow 使用目标应用 DPI 上下文，修复 150% 缩放时左上角绘制、其余留黑的问题；WGC 与完整窗口边界差异由映射字段说明。
- 继续不将窗口像素写入持久历史，compact 回执仅保留一份图片和简短摘要。工具数量不变，已有项目无需增加新的工具许可。

真实 mstsc 最小化约 90 秒期间，普通 Win32 窗口的 WGC/PrintWindow/auto、D3D11 画布的 WGC/auto，均通过中文写入读回、按钮单次调用以及橙→蓝→橙的两次画面更新验证。最终构建已再次通过实机完整链路，没有修改 RDP 客户端设置或现有安装。

完整流程与实机边界见 [窗口交互](INTERACTIVE_TOOLS.md)、[RDP 说明](REMOTE_DESKTOP.md)。真实按键/坐标和前台激活沿用原来的条件；其他应用的 UIA 提供者、受保护内容、多屏/HDR和其他机器仍需分别验收。Mac/Linux 未重新移植。升级后重新连接 MCP 客户端刷新工具定义。
