## 实现与使用

新增 `core/tools/desktop.c` 与 `WinShellBot/platform/desktop.c/.h`。C17 核心通过平台接口调用普通项目的原生桌面线程；管理员代理和旧单实例不提供该后端。主工程使用既有静态 CRT，新增 Windows GDI、WIC 与会话接口依赖，产品不需要 Python 或 Node。

十二个工具为 `desktop_lease`、`desktop_state`、`desktop_capture`、`window_list`、`window_focus`、`desktop_click`、`desktop_drag`、`desktop_scroll`、`desktop_type`、`desktop_key`、`clipboard_read`、`clipboard_write`。项目工具数从 15 增至 27；原有工具在默认关闭桌面时保持原发现与策略。

项目 format_version:1 增加可选 `policy.desktop`。观察、输入、剪贴板读写分别显式授权，工具列表仍设独立上限；默认为关闭。审批模式、目录范围、命令身份、管理员许可不自动授予桌面权限。即使文件只读，显式桌面观察仍可看到当前会话屏幕，不能把桌面能力当成目录隔离。`always` 和 `workspace_auto` 要求所有者逐次批准，`never` 只在明确权限内直接执行。完整用法及工具限制见 [DESKTOP_CONTROL.md](DESKTOP_CONTROL.md)，最小只读配置见 [desktop.example.json](../config/desktop.example.json)。

会话控制通过同账户、同会话受保护命名对象跨项目和跨管理器排他。租约绑定实例、项目与认证身份，默认 30 秒、最多 120 秒。普通管理器持有暂停事件，项目停止和异常退出不会清除人工暂停；进程死亡会释放控制锁和钩子。当前共享项目 Bearer 的客户端共享认证身份，不建立独立 MCP 会话。

每次观察最多保留 30 秒，最近 8 份；显示器布局、前台窗口、窗口位置、暂停或人工输入变化使旧观察失效。物理坐标与 PNG 缩放比例明确返回，裁剪仅在选定显示器内；PNG 只在内存编码，最大 1 MiB。输入检查目标会话、账户、进程创建标识和完整性，拒绝未知、更高权限、安全桌面及断开会话。Unicode 输入与按键成对提交，分批检查暂停，部分失败尝试释放已按下的键；返回事件接收数，不宣称应用业务成功。

默认 Ctrl+Alt+F9 只有实际注册成功后才允许控制。人工输入或其他程序模拟输入暂停整个会话；托盘入口可以暂停并经确认恢复，本机受保护所有者通道提供 `--desktop-status`、`--desktop-pause`、`--desktop-resume`，仍须指定相同 manager-data-dir。恢复使旧观察失效，MCP 和远程所有者 API 没有恢复入口。

桌面请求接入原审批、参数绑定、重试和历史。一个请求键在同一调用身份下不能换工具、参数或租约；完全相同的重试返回旧回执，不重放点击、输入或写入。图片、窗口标题、键入正文、剪贴板正文及审批参数只保留在当前进程内存；持久历史仅保存脱敏元数据。原每项目 64 条审批/操作记录上限仍有效，达到上限需复核并明确重启，不自动淘汰旧输入键。剪贴板写入通过序号比较，成功会替换全部格式；产品不自动为调用者恢复剪贴板。

## 修正、限制与验收

早期测试目录保留在 build/m8-tests；最终命名报告记录最后通过的一轮，未把所有早期失败报告分别归档。最初人工输入导致预期的保护暂停，随后获得用户静止配合再验证。两项产品问题在实际检查中修正：Windows 鼠标低级钩子截断 64 位 dwExtraInfo 导致自身事件被误判，改为随机正数 31 位标记；前台切换异步完成，增加最多 250 ms 的有界确认。外部模拟输入夹具由无位移事件改为实际一像素移动，Unicode 控件观测改为有界等待。

本轮没有 UAC、实际管理员回归、锁屏或安全桌面操作；以前 dev.14 的人工提权证据不能当作当前 dev.15 的提权验收。实际物理紧急停止键、托盘暂停/确认恢复、真实多显示器和不同缩放、锁屏/UAC/RDP 状态切换、独立 Windows 10/Server 2025 与实际 MCP 客户端仍须分别验收。自动热键事件不替代人工操作，当前本机成功不替代另一设备/既有公网代理。

没有 UI Automation 控件树、应用语义点击、浏览器后端、OCR、管理员桌面输入或持续屏幕录像。历史 HTTP close 重置仍未解决，核心回归明确使用 SkipCloseProbe。只读截图和窗口列表仍可能包含敏感屏幕内容，应由所有者按项目显式授权。
