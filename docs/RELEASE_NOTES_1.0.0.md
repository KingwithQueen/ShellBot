# ShellBot 1.0.0

发布日期：2026-10-21。第一个正式版，Windows x64 便携发布。单托盘调整：2026-10-22。

## 管理界面

采用已确认的项目优先排版：项目列表与新建在左侧，所选项目详情、设置和启停在右侧，连接、客户端授权和数据位置位于顶部。底部保留地址、诊断、令牌与数据路径。使用原生 Win32 菜单、系统控件和系统配色，支持快捷键、Tab 导航及 DPI 布局；视图菜单保留经典布局。

托盘统一为管理程序的一个图标，项目不再单独显示桌面控制图标。“桌面控制（本会话）”子菜单提供共享状态、全会话暂停/恢复与相关项目入口。关闭窗口继续后台运行，从托盘退出才停止本实例全部项目和任务。控制租约仍为 1～120 秒的单次期限，可显式续租，不限制项目运行时间。

界面按实际变化刷新，保留阅读位置、选区与诊断内容。短暂连接失败保留最后状态，禁止过期状态下的项目操作；旧项目异步诊断不会覆盖新选择。项目表单支持 Enter 保存和 Escape 取消，客户端授权的默认 Enter 动作只关闭窗口。

## 版本与兼容

程序、关于窗口和 MCP 返回版本均为 **1.0.0**。ShellBot.exe、WinShellBot.exe 和 ShellBot-SandboxProbe.exe 含统一的 Windows 产品与文件版本信息。MIT 版权署名为 **2026 姬敬**。

图标补全：采用用户提供的透明 PNG，生成包含 16、20、24、32、40、48、64、96、128、256 像素的 ICO 并嵌入三个 EXE。管理窗口、表单和唯一的管理托盘使用同一图标。版本保持 1.0.0，原始正式包与历史 `-branding` 包保留，当前统一托盘包以 `-single-tray` 区分。

沿用既有 37 项 MCP 工具、项目权限、便携数据和 OAuth 长期授权行为。OAuth 写入格式仍为 v3，兼容 dev.26–dev.28 的现有数据；旧 v1/v2 连接保留限时规则，不自动升级为长期。升级步骤见 [使用说明](USER_GUIDE.md)。

## 验证范围

本版重新构建 Debug 与 Release，执行绑定当前程序摘要的本机自动化：完整核心协议、两种界面排版、刷新与异步状态、原生控件和表单、桌面入口/退出、OAuth 续期与撤销、便携数据迁移，以及文件、图像、文档和传输等主要流程。Release 的 OAuth 检查包含实际等待授权码到期；HTTP 检查包含严格 EOF。

发布包核对全部文件摘要、许可证、Windows 版本属性及无私有数据，再从 ZIP 实际解压运行界面和入口流程。准确程序、报告与范围以包内 `validation/acceptance.json` 及本机 `build/release-1.0.0` 为准。

开发机继续保留 AdGuard 服务及 localhost 过滤，网络回归使用现有四个固定路径排除；没有停用过滤或修改隧道。实际解压目录的 GUI 验证与固定路径的 TCP 回归分别记录。

真实 MCP 客户端在本版上的持续续期、实际 UAC、物理多屏 DPI、其他 Windows 系统和长期运行仍需各自环境验收。本机自动化不代替这些结果。历史包、基线和原始失败记录保留，清理只移除核验过的重复解压文件及可重建缓存。
