# ShellBot 1.0.0 单托盘调整

日期：2026-10-22。按用户要求，管理程序是本实例唯一的托盘图标；各项目不再单独注册桌面控制图标。版本继续为 **1.0.0**，沿用已采用的项目优先界面和自定义图标。

## 当前使用方式

右键管理托盘，打开“桌面控制（本会话）”：

- 查看实际暂停状态及是否有桌面控制租约。
- “暂停全部桌面操作”作用于当前 Windows 登录会话中的全部 ShellBot 项目；文件工具和后台命令继续运行。
- “恢复桌面操作…”需要确认，等待 500 毫秒后才发送本机所有者请求；期间新的本机输入会取消恢复。恢复使旧观察失效，不重放动作。
- “查看项目”列出已经启用桌面控制的项目，选择后打开管理窗口并定位该项目。项目名称中的 `&` 正常显示，菜单持有项目标识，避免刷新时误选另一项目。

窗口右上角关闭和 Alt+F4 继续收进托盘，项目与任务继续运行；从托盘“退出 ShellBot（停止全部项目）”或文件菜单退出时，停止本实例全部项目、任务和网关。托盘暂不可用时窗口保持可见，等待恢复。桌面后台仍保留隐藏窗口和消息循环，用于租约、热键与安全监测；隐藏窗口不等于托盘图标。

## 控制租约的时间含义

`lease_seconds` 是单次桌面控制权的最长有效期，1～120 秒，默认 30 秒。它适用于需要租约的桌面观察、截图、窗口、键鼠与剪贴板工具，不是项目运行时长、命令任务超时或 OAuth 连接期限。

调用方可在到期前使用 `desktop_lease` / `renew` 显式续租，期限从成功续租时重新计算，仍不能超过项目上限，仍遵守项目审批规则。一般桌面调用不会自动延长租约。到期后旧租约失效，可重新申请；到期不停止项目或命令任务，也不撤销客户端连接。已经提交给 Windows 的输入不能由租约到期回滚。本轮未改租约上限或授权策略。

## 实现和验证边界

- `WinShellBot/platform/desktop.c` 去掉项目通知图标注册、重试、菜单及删除逻辑；保留租约计时、桌面安全监测、独占控制和热键。
- `manager_ui.c` 集中菜单和项目入口。状态从受保护的本机会话读取，变更走既有所有者管理通道并记录审计；远端 MCP 没有新增恢复入口。异步失败不会显示为恢复成功，退出会取消待恢复计时。
- 本轮源码和两个配置的运行组件备份位于 `build/baseline-single-tray-1.0.0-20261021-235721/manifest.json`。后补的 README 与启动说明也在同一清单。
- 本轮记录独立放在 `build/single-tray-1.0.0`，不覆盖前两轮正式版或图标版的冻结报告。
- `single_tray_checks.py` 使用真实 GUI、三个新建测试项目、实际 Windows 图标矩形查询与原生菜单读取，检查唯一管理图标、两个桌面工作进程无图标、会话暂停/恢复、确认取消与 500 ms 延迟、跨项目租约互斥、实际续租及到期、关窗后台运行、限定到测试窗口的托盘恢复消息和退出清理。不注入键鼠、不改剪贴板、不重启 Explorer。
- 初次专项中的文件列表请求误带了桌面工具专用参数，测试已修正，原失败报告、日志和当时脚本保留。产品文件与权限逻辑未因此改变。

发布门禁要求 Debug / Release 的单托盘专项，加既有 25 份当前程序回归，共 27 份报告，以及六个 EXE 的 60 帧原生图标解码。确切结果、文件集和摘要见 `acceptance.json`、`package-receipt.json`、`extracted-runtime.json`、`final-verification.json`。实际解压验证包含两种布局、GUI 入口和单托盘专项。物理输入取消、物理 Explorer 重启、多屏 DPI、实际 UAC、真实客户端及长期运行不由这些自动检查替代。
