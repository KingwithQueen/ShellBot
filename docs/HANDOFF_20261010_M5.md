## 本阶段实现

普通管理器持有一个共享的提升代理。administrator-start 在独立线程请求 UAC 并立即返回 administrator_starting，所有者轮询 administrator-status。等待期间普通工具/任务和停止入口保持可响应；重复 start/status 不新增启动尝试。只有本机所有者能启动、停止、注册项目、更新管理员许可或处理管理员批准；MCP 无此接口。

新 shared_admin.c 在代理内部解析管理器注册的项目快照，验证真实普通 worker 进程及令牌并持续持有其句柄。每次操作检查项目、配置/授权版本、实例、固定调用主体、规范参数摘要、单调序号、期限和原审批策略。worker 转发必须与网关/本机已经认证的工具请求完全一致；代理不接受自报 approved。管理器核验真实 ShellExecute 进程句柄、私有管道客户端 PID/令牌/SID/会话，代理核验服务器 PID、普通管理器令牌与程序路径，管道单连接、不继承、拒绝远程连接。

正常 current_user 文件范围且 current_user 默认命令身份的项目，经配置或运行期 allow 授权，显式 identity:administrator 使用提升文件/任务后端。六个文件工具与五个任务工具发布 identity 字段；task_status/output/input/cancel 继续携带 identity。普通默认任务仍使用原后端，管理员请求失败不转成普通执行。restricted/configured/legacy 项目不可注册共享代理。

代理按项目保持独立审批、任务、输入、幂等、备份和审计，Data 位于原项目 Data 下的 administrator-普通worker实例 子目录，目录物理身份由管理器固定。管理员审批使用 project-administrator-owner；普通 project-owner 的批准不能消费代理记录。HTTP project-mcp 与本机 manager-owner 的批准/任务继续隔离。

allow/revoke 更新当前授权版本，撤销阻止新操作、失效旧批准并取消本项目管理员任务；重新授权不复活旧批准。project-stop 或普通 worker 异常退出取消其管理员 Job，不关闭其他项目的任务或共享代理。代理崩溃关闭其 Job；管理器正常退出清理全部工作进程、代理和活动任务。任务新建、输入/EOF 重试、期限和输出沿用原有有界处理，没有自动重放。

## 两处实际修复及启动取消

管理员原生夹具创建受保护文件后，原 cwd 内容快照会读取该目录所有文件，导致普通 native task 连启动也失败。现在命令审批/执行复核绑定实际 cwd 目录对象的身份和元数据版本，不读取全部子文件；确切程序文件仍绑定版本、启动时内容 SHA-256 和持有的读句柄。cwd 不是依赖内容保证或执行沙箱；文件列表、搜索、读取仍用原逻辑版本检查。

旧同步 UAC 启动会占用管理员锁，等待超过本机通道 30 秒时拖住请求和退出。现在独立启动上下文不引用管理器或项目内存，仅在握手、身份核验和凭据清除全部完成后发布可用代理。administrator-stop 可以标记取消启动发布；Windows 弹窗仍需用户拒绝，晚到允许产生的代理会关闭。终止管理器时至多短等启动线程，随后直接退出进程，由操作系统回收尚待 UAC 的线程/独立上下文；晚到代理不能绑定已退出管理器或收到项目。

原生专项实际观察到启动中状态，并证明普通能力查询和 native task 仍能完成；最终拒绝 UAC 的状态为 administrator_alive:false、administrator_starting:false、administrator_generation:0、administrator_launch_attempts:1、startup_error 含 cancelled。状态轮询没有重新启动。

## 使用与继续开发

完整操作说明见 [共享管理员代理](SHARED_ADMINISTRATOR.md)，权限及配置见 [EXECUTION_PERMISSIONS.md](EXECUTION_PERMISSIONS.md)、[PROJECT_CONFIGURATION.md](PROJECT_CONFIGURATION.md)。常规回归不需要人工操作：

```powershell
.\scripts\build.ps1 -Configuration Debug
.\scripts\build.ps1 -Configuration Release
.\scripts\test.ps1 -Configuration Debug -SkipCloseProbe
.\scripts\test.ps1 -Configuration Release -SkipCloseProbe
```

只有涉及提升和生命周期改动才运行人工专项，不为纯文档更新重复 UAC：

```powershell
.\tests\Test-ShellBot-SharedAdministrator.ps1 -Configuration Release -Administrator
# 此次弹窗点击否
.\tests\Test-ShellBot-SharedAdministrator.ps1 -Configuration Release -CancelStartup
# 此次弹窗点击是
.\tests\Test-ShellBot-SharedAdministrator.ps1 -Configuration Release -AdministratorShutdown
```

以下边界必须保留：

- shared agent 仅接受同账户、同会话提升；跨账户明确失败，不宣称已兼容。旧单实例诊断和新共享协议不能混用。
- allow/revoke 为当前管理器运行期更新，返回 persisted_to_registry:false；永久改动导出配置并明确重启，重启恢复保存的许可但仍需显式启动/UAC。
- 普通/管理员任务及审批预算分别有界，当前不是合并项目配额；管理员进程不受普通 worker Job 的内存配额约束。
- LPAC 是声明资源的原生后端，禁止子进程、网络和 Win32k；不是所有工具都可用，不隔离已信任的普通账户/管理员程序。
- 撤销不回滚副作用，当前任务/批准不跨进程恢复；M6 的持久状态必须标记重启中断，禁止自动重跑和重复写入。
- 公网 OAuth、隧道安装/监管和域名探测继续暂缓；不修改旧打包器证据门槛或重新生成冻结包。
- 历史 HTTP close 偶发重置保持 needs_investigation，不用单轮通过宣称已修复；真实隧道及 MCP 客户端使用另验收。

继续时先核对最新 Git 状态、当前程序和报告，不能把本文的未提交状态当作未来事实。M6 从独立所有者认证、受保护有界持久记录、审批状态/取消/期限及重启中断审计开始；当前 project-mcp 只允许申请/查询/取消本人请求，不能获得批准凭据。需要远程设备实际验收时再安排用户操作。
