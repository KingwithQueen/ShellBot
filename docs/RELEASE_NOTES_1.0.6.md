# ShellBot 1.0.6

Windows 正式版，发布包命名为 `ShellBot-1.0.6-windows-x64.zip`，包含本地 ZIP 更新器。升级后重新连接 MCP 客户端以刷新新增工具定义。保留原 Data、位置设置、Windows 账户和授权记录。

- 增加 `task_list`、`task_archive`。调用方可查看本人任务、保存输出后归档已结束任务，同时释放实时任务资源及该任务的终结操作回执，避免再次碰到 64 份操作回执预算。预算错误区分活动数、任务记录和操作回执，并返回实际计数及上限。精简归档回执保留请求键，重试不会再次启动命令。持久历史占用另行报告。
- 窗口观察过期回执列出变化字段、前后值及相关窗口；目标窗口失效也给出具体变化。修复暂停/恢复后定时器使新观察过期的竞态。
- 截图明确区分抓屏、PNG 编码、体积上限和结果序列化失败，返回阶段、Windows 原生错误、HRESULT、已知的 PNG 字节数及桌面可捕获状态。

用法见 [后台任务](COMMAND_TASKS.md) 和 [桌面控制](DESKTOP_CONTROL.md)。此轮集中优化 Windows，Mac/Linux 新接口移植和原生验收另行进行。

验证使用隔离项目、临时安装和测试专用任务。包含任务配额、归档后持续执行、跨调用方隔离、重启幂等保护，以及原生桌面诊断、真实 GDI/WIC 编码和本地错误注入。完整键鼠回归在取得测试窗口焦点时被 Windows 拒绝，未进入输入阶段；这项现场验证尚未完成。实际 UAC、锁屏/断开会话、独立设备及外部客户端未在本轮重跑。随包 `validation-summary.json` 给出当前构建的准确验证范围。

文件修改回归曾因测试文件独占打开失败而中止，原始失败已保留；同一构建单独复测通过。文件独占保护保持有效。
