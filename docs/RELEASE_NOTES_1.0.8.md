# ShellBot 1.0.8 Windows

正式版包名为 `ShellBot-1.0.8-windows-x64.zip`，包含本地 ZIP 更新器。此轮仅优化 Windows，保留独立 Mac 改动；Mac/Linux 移植未重新验收。

- 组合键能力报告与项目工具发现一致，区分后端实现和当前授权，并说明不可用原因。工具列表不再随锁屏/会话临时状态漂移；不会自动扩大项目权限。
- 修正前台窗口 null / 未知矩形造成刚刷新观察就过期的问题。window_focus 从空前台窗口检查目标权限；直接按键、鼠标输入仍拒绝未知前台目标。
- 截图直接 StretchBlt 失败后尝试同设备复制与内存缩放，保留初次和最终错误。两条路径均失败时仍明确报错，PNG 编码/容量错误保持独立。
- task_archive 支持 task_ids 服务端串行批量请求，每项独立回执与幂等重试；后台回收已归档任务线程，移除请求路径的无限等待；项目繁忙时明确 HTTP 429 未排队及重试时间。

- 更新器对本次解压缓存的短时文件占用重试清理（最多 9 次、间隔 250 ms）；持续占用时保留 cache_warning，不删除备份或用户 ZIP。

用法见 [桌面控制](DESKTOP_CONTROL.md)、[命令任务](COMMAND_TASKS.md) 和 [更新说明](UPDATING.md)。升级或更改工具白名单后重新连接 MCP 客户端刷新定义。

验证范围：本地后台 MCP/HTTP 回归、原生桌面故障注入、真实普通桌面截图、批量及并发任务归档、正式包解压及更新校验。原反馈机器错误 5、外部客户端工具缓存、实际应用聚焦/组合键、UAC/安全桌面和独立 Mac/Linux 尚需对应环境验收。故障注入使用测试程序模拟失败，不能代替原反馈环境复测。准确结果随正式包 validation-summary.json 保存。
