# ShellBot 1.0.4

Windows 数据容量优化版。源码编辑从 64 KiB 提高到 8 MiB，文件上传/下载从 64 MiB 提高到 4 GiB，传输分块最高 1 MiB；图像源提高到 64 MiB / 64 MP，原生图像返回提高到 16 MiB。完整表格和保留限制的原因见 [数据容量](CAPACITY_LIMITS.md)。

命令行引号处理改为精确计数，避免普通长参数被提前拒绝。命令仍遵守 Windows 的系统总长；长源码可先写入脚本文件或经标准输入传入。参数个数提高到 1024，标准输入单次最高 1 MiB，任务输出单页最高 1 MiB，新项目每输出流默认留存 4 MiB，项目可选最高 64 MiB。

文档输入、提取文本、Office 部件与展开容量、桌面截图、剪贴板、目录分页和搜索容量一起提高。Office 长文本节点按块读取，降低提取时的临时内存。工具发现与参数验证从同一组容量生成，项目工具说明保留具体用法。配置文件容量和文件正文容量分开，大块传输按需分配，stdio 和任务输出缓冲逐步增长。大内容的持久历史保留预览、长度与摘要，完整审批/回执在当前实例中保留，避免复制图像和大正文挤满日志。

已有项目显式设置的资源配额保持有效，新项目默认 worker 内存为 1024 MiB。上传仍校验完整 SHA-256，重试仍避免重复追加，已有文件覆盖仍核对摘要并先备份。升级前退出旧版，保留 Data、位置设置和 Windows 账户。

本轮本地自动化覆盖 Windows Debug/Release 构建、容量边界、真实后台子进程、回环 HTTP、项目 worker、源码修改、较大文件双向传输和独立图像解码。逐项结果以随包验证摘要和本地 `build/limits-1.0.4` 收据为准。测试包不等同于完整正式发布门禁；实际管理员/UAC、实体桌面/剪贴板、多屏、外部 MCP/网关及完整 4 GiB 数据传输仍须另行验收。

Mac/Linux 本轮不重新移植、不生成新平台包；其数据容量保持原值，待 Windows 方案完善后再同步。
