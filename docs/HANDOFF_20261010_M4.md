## 边界与下一步

M4 初期只支持兼容声明资源、无网络/Win32k/子进程的原生程序。PowerShell、GUI、COM/注册表/子进程依赖的构建工具可能失败，不会退回账户或管理员身份。LPAC 使用 Windows 平台资源及自身 profile，并非只可见 cwd 的虚拟机；文件/目录版本使用对象身份和元数据，修改同时核验原始正文摘要。脚本及动态依赖不会仅凭 argv 自动全部固定。

项目管理员仍不可用，legacy controlled 也不因 M4 自动开放；旧 user/administrator 单实例行为保留。M5 需管理器持有共享提升代理、可信项目注册、版本/操作独立核验、逐项目授权与撤销、管理员文件和命令后端；原生测试分别验证 A/B 允许、C 拒绝及 UAC 后代理复用，不能只检查请求中的 project_id 或 approved。

M6 前批准/任务主要在内存，不跨重启恢复；远程所有者审批、持久中断和完整任务生命周期审计尚未接入。独立 Windows 10/Server 2025、真实 MCP 客户端、已有公网隧道与第三方工具兼容性待验收。历史 Connection: close 偶发重置未修复；核心明确跳过 close、管理员启动及开发机不可用的硬链接夹具，不当作通过。
